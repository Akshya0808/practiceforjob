| `check()`        | Checkbox/radio select       |
| `uncheck()`      | Checkbox unselect           |
| `selectOption()` | Dropdown                    |
| `hover()`        | Mouse hover                 |
| `dblclick()`     | Double click                |
| `focus()`        | Element focus               |
| `clear()`        | Input clear                 |
| `dragTo()`       | Drag & drop                 |
